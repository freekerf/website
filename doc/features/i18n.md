# Languages

**Purpose:** the site in English (source) and Brazilian Portuguese, page for page.

**Behaviour:**

- Routes: English at the root (`/`, `/download/`), other locales under their prefix
  (`/pt-br/`, `/pt-br/download/`). `src/lib/i18n.ts` builds and splits these paths.
- Strings live in `src/i18n/en.ts`; `src/i18n/pt-br.ts` has the type `Strings`, so a
  missing key fails `npm run check`. `{name}` placeholders are filled by `t()`.
- Each page sets `<html lang>`, `<link rel="alternate" hreflang>` for every locale plus
  `x-default`, and a canonical URL. The 404 page has none and its language links go to
  each home page.
- The header's language switch links to the same page in the other locale.
- Dates use the locale's format (`Intl.DateTimeFormat`, UTC).

**Adding a locale:** add it to `LOCALES`, `LANG_TAG`, `LANG_NAME` (`src/lib/i18n.ts`) and
to `i18n.locales` in `astro.config.mjs`; add `src/i18n/<locale>.ts` and the routes under
`src/pages/<locale>/`; add its pages to `PAGES` in the end-to-end tests.

**Tests:** `tests/unit/i18n.test.ts` (same keys and placeholders in every locale, the name
FreeKerf, paths round trip, dates), `tests/integration/build.test.ts` (every page in every
locale with `lang` and `hreflang`), `tests/e2e/site.spec.ts` (language switch).
